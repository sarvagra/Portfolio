### 🚀 Overview

A terminal-inspired, interactive developer portfolio showcasing machine learning architectures, data science projects, and academic milestones.

- **🎨 Theme:** Cyberpunk / Terminal Dark Mode with dynamic micro-interactions
- **⚡ Tech:** Vanilla HTML5, Modern CSS3 & JavaScript (No heavy frameworks)
- **📱 Experience:** Fully responsive with tabbed project galleries and interactive cards
